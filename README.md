# Arconte · descargas

Aquí se publican las versiones de **Arconte** para Windows.

**[Descargar la última versión →](https://github.com/Abarza1/arconte-descargas/releases/latest)** (archivo `Arconte.exe`)

1. Descarga `Arconte.exe` y ábrelo.
2. Si Windows muestra «Windows protegió su PC», haz clic en **Más información → Ejecutar de todas formas** (el programa aún no tiene firma digital).
3. Presiona **Elegir carpeta…**. Arconte la lee sin modificar nada y abre la sala en tu navegador.

Todo ocurre en tu computador: Arconte no envía tus archivos a ninguna parte. Al abrirse solo consulta esta página para avisarte si hay una versión nueva.
